# Blueprint Code

1. Typed variables: number, string, boolean, any, array
2. Type conversion: toNumber, toString, toBoolean, toArray
3. Math expressions and math helpers
4. Boolean logic and comparisons
5. Delays in milliseconds
6. User inputs with live controls
7. Text and number outputs
8. Conditions with if / else / end
9. Repeat loops with repeat / times / end
10. Save and load complete projects as .bpc files

Additional features include constants, live variable inspection, error reporting with line numbers, keyboard editing, local draft recovery, stop/run controls, mobile responsive layout, and a browser-only execution engine.
