Host

Starts the WebRTC peer and shares the selected screen. Input events are applied only to the host webpage.

Controller

Receives the screen and sends pointer/keyboard events through a WebRTC data channel.

Browser limitation: a normal webpage cannot generate arbitrary OS-level mouse clicks or keyboard presses. This app controls the host webpage, not Windows/macOS/Linux itself. Full-PC control requires a native host app or browser extension with extra permissions.
