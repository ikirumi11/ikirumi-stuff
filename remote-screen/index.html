How it works

Both devices open this exact same page. One selects Host, the other selects Controller. The host shares a screen and gets a six-character room code. The controller enters that code.
Browser limitation: this version can forward input to the host webpage, but a normal browser cannot generate arbitrary OS-level mouse or keyboard input. Full Windows/macOS/Linux control needs a separate native host application with explicit permissions.
