IKIRUMI STUFF CONTAINER

This repository is a container for Ikirumi Stuff sites.

Site folders can use either numbered names or custom names:

Root/
├── site1/
│   └── files for Site 1
├── site2/
│   └── files for Site 2
└── MySite/
    └── files for a named site

Numbered folders such as site1 and site2 automatically display as Site 1 and Site 2.
Named folders can display a custom name using site-names.json. For example:

{
  "MySite": "My Cool Site"
}

Each site folder must contain its own index.html to be considered ready to open.
The root is kept clean and is used for the site folders and container configuration files.
