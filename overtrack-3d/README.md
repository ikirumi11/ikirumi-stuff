# Overtrack 3D

A browser-based first-person 3D racing game.

- Procedural seeded 3D tracks
- Cockpit/inside-car camera
- Driving with WASD or arrows
- Handbrake drifting
- Trees, barriers, road markings and terrain
- Random or custom seeds
- Finish timing
- Touch controls

Uses Three.js from a CDN. Three.js provides the scene, camera, renderer, lighting and 3D geometry used by the browser game.
